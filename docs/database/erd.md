# Mealio Database Schema

This document describes the initial database schema for the Mealio application.

The schema is designed for a mobile application that allows users to manage available ingredients, generate recipes using AI, calculate nutritional values, and create meal plans.

## Main Entities

The first version of the database contains the following tables:

```txt
users
ingredients
nutrition_values
user_ingredients
recipes
recipe_ingredients
meal_plans
meal_plan_items
recipe_ai_requests
