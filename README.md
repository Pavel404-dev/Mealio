# Mealio

Mealio is an AI-powered mobile application for generating recipes from ingredients that users already have at home.

The application is developed as part of a Bachelor's Thesis.

## Main Goal

The main goal of Mealio is to help users create recipes from available ingredients, classify meal types, calculate nutritional values, and provide healthier lifestyle recommendations using artificial intelligence.

## Planned Technology Stack

### Mobile Frontend

- Flutter
- Dart

### Backend

- Python
- FastAPI

### Database

- PostgreSQL
- SQLAlchemy
- Alembic

### AI

- AI recipe generation service
- Recipe classification
- Nutrition recommendation logic
